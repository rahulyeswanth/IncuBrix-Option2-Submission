# Product walkthrough script — maximum 5 minutes

Do not rehearse claims that are not visible. Record unedited and hide passwords,
private email, API keys, and unrelated customer data.

| Time | On screen | What to explain |
|---|---|---|
| 0:00–0:25 | Title card, date, signed-in product | Candidate identity and what will be tested |
| 0:25–1:10 | Real input upload/open | Input type, length, and consent/rights |
| 1:10–2:00 | Content insights | Suggestions shown, what is useful, and what is missing |
| 2:00–3:10 | Creation/editing | Clip selection, transcript/captions, actual elapsed time |
| 3:10–3:50 | Publishing screen | Available destinations and whether scheduling works; do not publish to an unauthorized brand account |
| 3:50–4:25 | Failure/limitation | One genuine issue, unavailable feature, or “coming soon” state |
| 4:25–5:00 | Summary | Five observation evidence links and three growth opportunities |

After recording, update `claims.json` only for features visibly demonstrated,
using the recording URL and timestamp as evidence.
